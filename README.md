# Resik For Schooling

Aplikasi bank sampah sekolah: siswa dan warga menyetor sampah, saldo tercatat otomatis, dan pengelola memantau semuanya lewat dashboard admin.

## Fitur
 
**Aplikasi nasabah**
- Login (Google Sign-In / Firebase Auth) dan pengaturan **PIN** untuk keamanan
- Dashboard saldo & **riwayat transaksi** (setor dan tarik)
- **Kartu nasabah** dengan QR code, bisa disimpan/dibagikan
- Detail transaksi dan **ekspor PDF**
- Notifikasi lokal saat ada transaksi baru
**Dashboard admin (`web-admin/`)**
- Dashboard ringkasan dan grafik
- Kelola nasabah, **kategori sampah** & harga per kg
- Catat transaksi setor/tarik, **scan QR** kartu nasabah
- Stok, keuangan, keuntungan, raport, dan pengumuman
